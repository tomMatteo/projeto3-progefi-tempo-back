# API DE PREVISÃO DE TEMPO E LOCAÇÃO DE ROUPAS

### BACKEND DO PROJETO 3 DE PROGRAMAÇÃO EFICAZ

O objetivo dessa API é receber três coisas:
- Localizações (cidade ou coordenadas)
- Quantidades de roupas
- Dias de uma viagem

E, a partir disso, gerar uma locação baseada na previsão de tempo de cada dia.
Caso a API receba uma coordenada, ela vai calcular o dia baseado no lugar específico. Caso contrário, calculara a previsão do dia inteiro.


## APIS e bibliotecas utilizadas:
- ### Nominatim
API usada para transformar endereços em coordenadas.

nominatim.org

- ### Open Meteo
API usada para ter a previsão do tempo para cada dia em cada lugar.

open-meteo.com
